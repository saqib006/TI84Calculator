# TI-84 Calculator Online

A free online TI-84 Plus CE calculator emulator for graphing, mathematical calculations, and statistical analysis. Access the calculator through your web browser without installing additional software.

## 🌟 Features

* **Graphing Calculator** - Explore mathematical functions and graphing tools.
* **Browser-Based Access** - Use the calculator without installing separate software.
* **Cross-Platform Compatibility** - Access it on compatible Windows, macOS, Linux, iOS, and Android devices.
* **Adjustable Zoom** - Resize the calculator display for comfortable viewing.
* **Responsive Interface** - Designed for desktop, tablet, and mobile screens.
* **Free Access** - No registration or payment required.

## 📊 Calculator Capabilities

Depending on emulator support, available features may include:

* Function graphing, parametric equations, polar graphs, and sequences
* Statistical calculations, regression analysis, and statistical plots
* Matrix operations
* Complex number calculations
* Trigonometric, logarithmic, and exponential functions
* List operations and table generation
* TI-BASIC programming support

## 💻 Local Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/saqib006/TI84Calculator.git
cd TI84Calculator
```

### 2. Open the Project

Open `index.html` in your web browser.

Alternatively, start a local development server.

**Using Python:**

```bash
python -m http.server 8000
```

**Using Node.js:**

```bash
npx http-server
```

### 3. Access the Local Website

Open the following address in your browser:

http://localhost:8000
